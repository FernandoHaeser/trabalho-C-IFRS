# trabalho-C-IFRS

This repository contains C language projects and assignments developed for IFRS (Instituto Federal do Rio Grande do Sul). The projects are intended for academic purposes and demonstrate fundamental programming concepts in C.

## Branch: fernando-haeser

This branch contains the personal work and solutions by Fernando Haeser. All code and documentation here reflect Fernando's approach to the assignments and exercises proposed during the course.

## Features

- 100% C language
- Academic exercises and project solutions
- Focus on fundamental programming logic and problem-solving

## Getting Started

To compile and run the code in this repository:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/FernandoHaeser/trabalho-C-IFRS.git
   ```
2. **Switch to the fernando branch:**
   ```bash
   git checkout fernando
   ```
3. **Navigate to the desired project or exercise directory.**

4. **Compile the source code:**
   ```bash
   gcc <filename>.c -o <output>
   ```
   Replace `<filename>.c` with the name of the C source file and `<output>` with the desired output executable name.

5. **Run the program:**
   ```bash
   ./<output>
   ```

## Requirements

- GCC or any C compiler
- Git (for cloning the repository)
